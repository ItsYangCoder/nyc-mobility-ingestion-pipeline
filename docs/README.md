# Documentation

- `architecture/`: confirmed data model and future ERD/architecture diagrams
- `contracts/`: source schema, units, timezone, and lineage contracts
- `profiles/`: individual Bronze profiling evidence
- `runbooks/`: raw landing and end-to-end execution instructions
- `evidence/`: acquisition, validation, reconciliation, and final acceptance evidence

Keep documentation concise and link to run results rather than committing large logs or datasets.
